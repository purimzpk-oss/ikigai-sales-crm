# Ikigai Sales (เวอร์ชันไฟล์เดียว)

เว็บเซลล์ทั้งระบบอยู่ในไฟล์เดียวคือ `index.html` ทำแบบเดียวกับ ikgthaifarm.com:
ไม่ต้อง build ไม่ต้องลงโปรแกรม แก้ไฟล์แล้วอัปโหลดทับก็เสร็จ

- ข้อมูลและการล็อกอินอยู่ที่ Supabase โปรเจกต์ **ikigai-sales-crm** (ใช้ตารางเดียวกับแอป Next.js ใน repo นี้)
- สิทธิ์หัวหน้า/เซลล์ บังคับที่ฐานข้อมูล (Row Level Security ใน `supabase/schema.sql`) เซลล์เห็นเฉพาะลูกค้าของตัวเอง
- แผนที่ใช้ OpenStreetMap ลิงก์นำทางไป Google Maps

## มีอะไรบ้าง
| หน้า | ใช้ทำอะไร |
|---|---|
| หน้าเข้าสู่ระบบ | เข้าสู่ระบบ, สมัครสมาชิก (รอหัวหน้าอนุมัติ), ลืมรหัสผ่าน, **ทดลองใช้ด้วยข้อมูลตัวอย่าง** ไม่ต้องล็อกอิน |
| ภาพรวม | ยอดปิดเดือนนี้เทียบเป้า, มูลค่าดีลเปิด, คาดการณ์, กราฟ 6 เดือน, งานที่เลยกำหนด, ผลงานรายคน |
| ไปป์ไลน์ | ลากการ์ดเปลี่ยนขั้น (บนมือถือเลือก "ย้ายไป" ใต้การ์ด) |
| ลูกค้า | ค้นหา กรอง เพิ่ม แก้ไข โทร/LINE/นำทางในปุ่มเดียว, บันทึกการติดต่อ, งานติดตาม, ส่งออก CSV |
| เช็กอินเยี่ยมลูกค้า | ถ่ายรูปหน้าร้าน (สูงสุด 6 รูป) + บันทึกพิกัดอัตโนมัติ + นัดครั้งถัดไป |
| ใบเสนอราคา | เลือกสินค้าจากรายการ, ส่วนลด, VAT, ยอดเป็นตัวหนังสือ, พิมพ์หรือบันทึกเป็น PDF, อัปเดตมูลค่าดีลให้อัตโนมัติ |
| แผนที่ | หมุดลูกค้าตามสถานะ กดนำทาง |
| งานติดตาม | รายการงานที่ต้องโทร/เข้าพบ ติ๊กเมื่อเสร็จ |
| ตั้งค่า | ทุกคน: แก้ชื่อ เบอร์ เปลี่ยนรหัสผ่าน · หัวหน้า: อนุมัติ/ปิดบัญชีทีม, โอนลูกค้า, ประวัติสิทธิ์, แบรนด์ (ชื่อ โลโก้ สี ข้อมูลบริษัท), สินค้า, เป้ายอดขาย, นำเข้าจาก Google Sheet, สำรองข้อมูล |
| ติดตั้งเป็นแอป | เพิ่มไปหน้าจอโฮมของมือถือ เปิดเต็มจอเหมือนแอป |

## อัปเดตฐานข้อมูลเป็น v2 (ครั้งเดียว)
ส่วนสมัครสมาชิก สินค้า ใบเสนอราคา เช็กอิน และแบรนด์ ต้องรันไฟล์ `supabase/v2_team_products_quotes_visits.sql`
ใน Supabase → SQL Editor หนึ่งครั้ง (เพิ่มอย่างเดียว ไม่ลบข้อมูลเดิม) แล้วไปที่ **Authentication → Sign In / Providers**
เปิด "Allow new users to sign up" เพื่อให้ทีมสมัครเองได้ (คนที่สมัครจะเข้าไม่ได้จนกว่าหัวหน้าจะอนุมัติ)

## ขึ้นเว็บบน Cloudflare Pages (ครั้งแรก ~5 นาที)
1. เข้า https://dash.cloudflare.com → **Workers & Pages** → **Create** → แท็บ **Pages**
2. เลือกอย่างใดอย่างหนึ่ง
   - **ง่ายสุด:** Upload assets → ตั้งชื่อโปรเจกต์ เช่น `ikigai-sales` → ลากโฟลเดอร์ `web` ลงไป (ต้องมีครบทุกไฟล์: index.html, manifest.webmanifest, sw.js และไอคอน) → Deploy
   - **อัปเดตอัตโนมัติจาก GitHub:** Connect to Git → เลือก repo `ikigai-sales-crm` → Framework preset: **None**, Build command: เว้นว่าง, Build output directory: `web` → Deploy
3. จะได้ลิงก์ เช่น `ikigai-sales.pages.dev` ใส่โดเมนตัวเองได้ที่แท็บ **Custom domains**
4. ที่ Supabase → **Authentication → URL Configuration** ใส่ลิงก์เว็บใน **Site URL** (ให้ลิงก์ "ลืมรหัสผ่าน" ในอีเมลพากลับมาที่เว็บ)

## การดูแลประจำวัน
- **เพิ่มคนในทีม:** ให้เขาเปิดเว็บแล้วกด "สมัครสมาชิก" หัวหน้าเข้า ตั้งค่า → ทีม → อนุมัติ
- **แก้ข้อมูลจำนวนมาก:** แก้ในหน้าเว็บ หรือเปิด Supabase → Table Editor แก้เหมือนสเปรดชีต
- **แก้หน้าตาเว็บ:** แก้ `index.html` แล้วอัปโหลดทับ (หรือ push เข้า GitHub ถ้าเลือกแบบอัปเดตอัตโนมัติ)
- **สำรองข้อมูล:** หน้าลูกค้า → ส่งออก CSV

คีย์ Supabase ที่อยู่ใน `index.html` เป็นคีย์สาธารณะ (publishable) ใส่ในหน้าเว็บได้ตามปกติ ห้ามใส่คีย์ `service_role` ลงในไฟล์นี้
